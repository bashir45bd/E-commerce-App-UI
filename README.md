# 🛒 E-Commerce App UI (Flutter)

A **fully designed E-Commerce mobile app UI**, built with **Flutter**.  
This project showcases the **frontend design** of a modern shopping app — ready to integrate with a backend.

> ⚠️ **Note:** This project includes **UI design only**. Backend functionalities (such as authentication, payment, and database operations) are **not implemented** yet.

## 📱 Features (UI only)

- 🏠 Home Page with product list
- 🗂️ Category selection screen
- 📋 Product details page
- 🛒 Cart page
- ❤️ Wishlist screen
- 👤 User profile page
- 🛠️ Login & Signup screens (UI only)

## 🛠️ Built With

- **Flutter** (Dart)
- **Custom Widgets & UI components**
- **Responsive Design** (works on Android & iOS)
